# job-bot

Бот на Go, который ищет свежие вакансии под ваш профиль, оценивает их, готовит черновик сопроводительного письма и присылает карточку в Telegram. **Откликаетесь вы сами**: бот ничего не отправляет работодателям.

```
источники → фильтры → оценка → черновик письма → Telegram (кнопки «Откликнулась» / «Пропустить»)
```

## Что умеет

- **Источники** (только открытые и разрешённые способы):
  - карьерные страницы компаний на Greenhouse, Lever, Ashby (публичные API);
  - публичная RSS-лента Хабр Карьеры;
  - публичные Telegram-каналы с вакансиями (веб-версия `t.me/s/…`, аккаунт не нужен);
  - письма с рассылками вакансий по IMAP (hh.ru и др.), ящик открывается только на чтение.
- **Фильтры**: роль и стек, зарплата в пересчёте на USD, формат (удалёнка/гибрид в нужных городах), возраст вакансии, стоп-слова, исключаемые регионы, дубли между каналами.
- **Список «отложено»**: вакансии выбранных компаний сохраняются, но не показываются, пока вы не скажете `/unpark <компания>`.
- **Оценка 0–100** по правилам и цветной кружок релевантности в карточке (🟢/🟡/🟠).
- **Письма** на русском и английском: из шаблонов на ваших достижениях или локальной моделью через Ollama (с проверкой на выдуманные факты и откатом к шаблону).
- **Оповещения**: ошибки, паника, остановка и аварийное падение приходят в Telegram с ❗.
- **Команды бота**: `/status`, `/pause`, `/resume`, `/unpark <компания|all>`.

Чего бот не делает намеренно: не парсит сайты, которые это запрещают или защищены от ботов, не обходит капчи и не откликается автоматически.

## Быстрый старт

Нужен Go 1.27+.

```bash
cp config.example.yaml config.yaml        # профиль поиска: роли, стек, зарплата, источники
cp candidate.example.yaml candidate.yaml  # ваши достижения для писем
cp .env.example .env                      # TELEGRAM_TOKEN, TELEGRAM_CHAT_ID (и IMAP_* для почты)
```

- Токен: создайте бота у `@BotFather`. `TELEGRAM_CHAT_ID` — номер **вашего** чата (не бота), например через `@userinfobot`.
- Почта (необязательно): пароль приложения, не основной пароль. Подробности в комментариях `config.example.yaml`.

Запуск и проверка:

```bash
make test                                                     # тесты
go run ./cmd/dryrun -config config.yaml -max-age-hours 168    # что бот нашёл бы сейчас, без отправки
go run ./cmd/dryrun -config config.yaml -letters              # то же, с черновиками писем
make run                                                      # запустить бота локально
```

`dryrun` ничего не отправляет и не пишет в базу. `cmd/preview` отправляет вам в Telegram пример карточки.

## Выкладка на сервер

Бот собирается в один статический файл (SQLite без CGO), Docker не нужен. Сервер: Linux с systemd и доступом по SSH-ключу.

```bash
./deploy/deploy.sh user@host [amd64|arm64] [ssh-порт]
```

Скрипт прогоняет тесты, собирает бинарник, ставит службу `jobbot` и сторожа `notify-stop.sh`, копирует конфиги и при первом запуске `.env`. Серверный `.env` после этого не перезаписывается. Логи: `journalctl -u jobbot -f`.

## Структура

| Путь | Назначение |
|---|---|
| `cmd/jobbot` | сам бот |
| `cmd/dryrun`, `cmd/preview` | проверочные утилиты |
| `internal/source` | сборщики вакансий (ATS, Хабр, Telegram, почта) |
| `internal/filter` | жёсткие правила отбора |
| `internal/match` | оценка и письма (шаблоны, Ollama) |
| `internal/pipeline` | цикл сбора, оценки и отправки, контроль источников |
| `internal/store` | SQLite-хранилище |
| `internal/bot` | Telegram: команды и карточки |
| `internal/alert` | пересылка ошибок в Telegram с защитой от спама |
| `deploy` | служба systemd, скрипт выкладки, сторож |

## Конфиденциальность

В репозиторий не попадают `.env`, `config.yaml`, `candidate.yaml`, база и бинарники (см. `.gitignore`). Токены и пароли хранятся только в `.env`. Тесты используют нейтральный `candidate.example.yaml`.
